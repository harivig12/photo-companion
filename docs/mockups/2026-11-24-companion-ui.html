Photos companion: UI

Three options for the Jobs home screen (A, B, C), then the shared screens: sign in, create, suggestions, settings, states and phone. All data is made up.

  • Results always go back into Immich (album, tag, stack, Memories strip). This UI only shows thumbnails fetched through the Immich API.
  • Single user, one password (stored hashed). The Immich API key lives in .env and is never shown.
  • Follows the device theme (light "champagne" / dark "obsidian" from the shared design library). Use the button at the bottom right to flip it.
  • References used: design-library/guides/dashboards.md (lead with the answer, skeletons, grouping, states), tokens/tokens.css, Doctor Sem (Behance, KPI chips over a dense table) for A, Lisso (Dribbble, progress cards) for B, Nixtio "Dashboard UI" (Dribbble, progress rows) for C.
